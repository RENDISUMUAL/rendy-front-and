# 🧮 Kalkulator Modern Interaktif

Kalkulator modern berbasis web yang responsif, elegan, dan kaya fitur.

## ✨ Fitur Utama
1. **Desain Modern (Glassmorphism):** Tampilan visual elegan dengan efek blur, gradien, serta transisi halus.
2. **Tema Gelap & Terang (Dark / Light Mode):** Tersedia tombol pengubah tema (🌙 / ☀️) yang otomatis tersimpan.
3. **Operasi Matematika Lengkap:**
   - Standar: Tambah (`+`), Kurang (`-`), Kali (`×`), Bagi (`÷`).
   - Saintifik Dasar: Akar kuadrat (`√`), Kuadrat (`x²`), Persentase (`%`), Negasi (`±`).
4. **Riwayat Perhitungan:** Menyimpan riwayat operasi matematika terakhir dan dapat diklik untuk menggunakan kembali nilainya.
5. **Dukungan Keyboard Penuh:**
   - Angka: `0` - `9`
   - Koma / Titik Desimal: `.` atau `,`
   - Operator: `+`, `-`, `*`, `/`, `%`
   - Hitung: `Enter` atau `=`
   - Hapus satu digit: `Backspace`
   - Hapus semua (AC): `Escape`
6. **Efek Suara Audio Web:** Suara klik taktil lembut saat tombol ditekan (dapat dimatikan/dihidupkan dengan tombol 🔊).
7. **Responsif:** Nyaman digunakan di layar desktop maupun smartphone.

## 🚀 Cara Menjalankan
Cukup klik ganda (double-click) file **`index.html`** untuk langsung membukanya di browser favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).
